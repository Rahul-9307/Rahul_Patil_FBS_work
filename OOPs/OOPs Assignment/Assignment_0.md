# Assignment 0 : 10 Real-World Object Examples in OOP

## Introduction
Object-Oriented Programming (OOP) is a programming approach based on objects. An object represents a real-world entity and contains state, behavior, identity, and responsibility.

This assignment contains 10 real-world object examples to understand the basic concepts of OOP.

---

## 1. Object Name: Fan

### State
- Number of Blades: 3
- Color: Black
- Company Name: Bajaj
- Model: Maxima 600mm
- Price: ₹1500
- RPM: 300
- Motor Type: Induction

### Behavior
1. When I switch on the button, the fan starts rotating.
2. When I switch off the button, the fan stops rotating.
3. When I rotate the regulator clockwise, the speed of the fan increases.
4. When I rotate the regulator anti-clockwise, the speed of the fan decreases.

### Identity
- Serial Number: BAJ1234FAN20240721

### Responsibility
1. The fan should provide proper air circulation in the room.
2. The fan should start and stop correctly when the user operates the switch.
3. The fan should adjust its speed accurately according to the regulator setting.
4. The fan should operate safely and efficiently.

## Conclusion

Object-Oriented Programming represents real-world entities as objects.

- **Object Name:** Identifies the type of object.
- **State:** Describes the properties or data of an object.
- **Behavior:** Describes the actions performed by an object.
- **Identity:** Uniquely identifies a particular object.
- **Responsibility:** Describes what the object is expected to do.

These 10 examples help us understand how real-world objects can be represented using OOP concepts.

After completing this assignment, I understood how to identify objects, define their states and behaviors, assign unique identities, and describe their responsibilities in real-world applications.
